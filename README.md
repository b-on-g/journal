# bog/journal

Блог-платформа на **$mol/MAM** и **Гипер Базе**. Каждый автор ведёт свой журнал, лента собирает подписки в одну хронологию.

Прод: https://b-on-g.github.io/journal/

## Как устроено

- **Пост** — метаданные (`Title`, `Slug`, `Summary`, `Cover`, `Published`, `Tags`) лежат пешкой в ленде журнала, а тело статьи в отдельном ленде со страницей `$bog_wysiwyg_model_page`. Поэтому список постов стоит один синк ленда, а тело подтягивается только когда его открыли.
- **Журнал автора** — один ленд с пресетом `[[ null, read ]]`, то есть читается кем угодно, включая незалогиненного читателя.
- **Лента** — свой пешка со списком журналов, на которые подписан. Можно держать приватной в домашнем ленде или расшарить ссылкой.
- **Публикация** — это `Published` с ненулевым таймстампом. Контент никуда не деплоится: он уже на мастер-ноде, куда приехал обычным синком.

Редактор — отдельный проект [bog/wysiwyg](https://github.com/b-on-g/wysiwyg) (MIT).

## Разработка

```bash
# Внутри MAM workspace
# Dev server: http://localhost:9080/bog/journal/app/-/test.html
```

Роутинг path-based, а не hash: краулеры не ходят по `#`-ссылкам. На дев-сервере роутер намеренно отключён (guard на `.html` и `/-/`), поэтому deep-link'и проверяются на статик-стенде, имитирующем GitHub Pages.
