# Журналы, которые попадают в поисковую выдачу ПОМИМО каталога.
#
# Обычно тут пусто, и это нормально. Главный источник — публичный каталог
# журналов в самой Гипер Базе: журнал пишет себя туда, когда его создают, а
# обход читает каталог с главной страницы и сам знает про всех авторов. Файл
# нужен для трёх случаев:
#
#   * журнал завели до каталога и в каталог он не попал;
#   * журнал живёт вне каталога намеренно;
#   * каталог недоступен, а выдачу терять не хочется.
#
# Оба источника объединяются, дубли схлопываются сами.
#
# Одна строка — один журнал. Можно писать голую ссылку на ленд:
#
#     hFqK8s_2nvY0pDqXWmA1
#
# либо готовый маршрут, если нужен не корень журнала:
#
#     author=hFqK8s_2nvY0pDqXWmA1
#
# Пустые строки и всё после # игнорируются.
#
# Ссылку на свой журнал видно в адресной строке: часть после author= на
# https://b-on-g.github.io/journal/author=<вот это>
#
# Если пусто и каталог пуст, пререндерится только главная. Это не ошибка
# сборки.
